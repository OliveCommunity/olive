## 关于 Oak

Oak 视频编辑器是 Olive 的重命名分支，目标是打造更完善、更友好的剪辑体验。本网站提供构建说明、工程文件参考与测试计划等贡献者文档。

## 快速开始

- 按《[构建指南](./build-zh.md)》在 Windows/macOS/Linux 上从源码构建。
- 在《[工程文件参考](./project-file-reference.md)》了解项目数据结构。
- 按《[测试计划](./test-plan.md)》确保发布质量。
- 查阅《[预览系统优化](./preview-optimization.md)》进行性能调优。
