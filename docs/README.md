## About Oak

Oak Video Editor is a renamed fork of Olive, focused on delivering a polished, creator-friendly editing experience. This site hosts build notes, project file references, and test plans for contributors.

## Quick Start

- Build from source on Windows, macOS, or Linux using the [Build guide](./build.md).
- Learn how project data is stored in the [Project File Reference](./project-file-reference.md).
- Keep releases solid by following the [Test Plan](./test-plan.md).
- Check out the [Preview System Optimization](./preview-optimization.md) for performance tuning.
